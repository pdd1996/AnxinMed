# 外部知识兜底（百川医疗大模型）· 决赛演示版（23）

> 2026-11-19。状态：**演示/灰度已实现，待部署验收**；PRD §7.5 / ADR #20 的正式修订待裁决（A10–A14）。
> 目标：本地说明书库未收录的「非药品物质 × 药物同服」问题（如「酒和藿香正气水能一起吃吗」），不再只回 `no-source`，改由百川医疗大模型给一般性安全提示并明确标注「AI 生成，仅供参考」。

## 1. 触发条件（严格限定，纯规则）

`services/consult/external.ts`：

- 非药品物质关键词：酒/酒精/白酒/啤酒/红酒/黄酒/米酒、藿香正气水、西柚/柚子/葡萄柚、咖啡/浓茶/茶；
- 同服语义：一起/同时/同服/能不能/可不可以/冲突/相互作用/相克/忌口/有影响等；
- 药品语境：药/片/胶囊/口服液/头孢/甲硝唑/他汀/地平/洛尔/普利/沙坦/双胍/阿司匹林等；
- 排除：剂量/频次问题（`每次几片/每日几次/剂量/疗程`）——高风险个体化建议仍交 S0/说明书管线；
- 位置：S0 守门之后、S2 数据查询之后、S1 的 `no-source` 分支（无绑定药、无对象澄清时才触发）。

## 2. 模型与回退（fail-closed）

1. `BAICHUAN_API_KEY` + `BAICHUAN_BASE_URL` 已配置 → `baichuan-m3-plus`（温度 0，医学安全 prompt）；
2. 否则回落 `qwen3.8-flash` 文本模型（同 prompt；引用 version 会如实写实际模型名）；
4. 模型输出不符合 zod/安全清洗不过 → 固定通用提示（酒精类含「含醇制剂 + 双硫仑样反应」提示），notice 明确「AI 服务暂不可用」，不冒充 AI、不静默。

## 3. 输出契约（复用现有 status，不改状态机）

- `status='answered'`（旧 APK 可正常渲染；不新增状态、不改 consultStatusVersion）；
- `notice` = 「以下内容由 AI 生成，仅供参考；不是本地说明书证据，不能替代医生或药师的判断。」；
- `sections.warning` 追加「（AI 生成，仅供参考）」，保证旧客户端也能看到免责；
- `citations=[{ drugName:'AI 生成（通用医学知识）', source:'外部医疗大模型（非本地说明书，未经人工核验）', version:`<模型> · <日期>`, unverified:true }]`；fallback 时 source 为「人工配置的用药安全提示」；
- 落库 `consult_logs.status='answered'`、citations 含 unverified 标记；不进 risk_events（L1）。

## 4. 模型输出安全红线（`sanitizeExternalSections`）

命中任一即**整段弃用**并回退固定提示：

- 剂量/频次：`每次/每日/一天/疗程/剂量/多少片/毫克/mg/ml/毫升`；
- 绝对安全：`可以一起/可以同服/可以同时/放心吃/放心喝/可以喝酒/没问题/绝对安全/不会有风险/没有影响`；
- 越权建议：`建议停药/建议换药/开处方/诊断为/你得了/确诊`。
