## 4. 开关与回滚

| env | 默认 | 作用 | 回滚效果 |
|---|---|---|---|
| `ENABLE_INTENT_ROUTE` | 开 | S2 意图路由 | false = 自由文本全走 S1 |
| `ENABLE_SCOPE_GATE` | 开 | 诊断/非用药范围层 | false = 回退旧 S1 管线 |
| `ENABLE_OBJECT_CLARIFY` | 开 | 对象缺失澄清 | false = 回退 no-source |
| `ENABLE_ROUTE_NORMALIZE` | 开 | 语义归一化路由视图（T7） | false = 逐字节恢复归一化前行为 |
| `CONSULT_ROUTE_TRACE` | 关 | 开发期 trace 落盘 `.agent-debug/` | 关 = 零 I/O |
| `consultStatusVersion`（请求字段） | 旧客户端不带 | 客户端能力协商 | 不带 = 新状态降级 `no-source` |
