## 2. 范围分片（每片一个 commit、一条独立验收，顺序即依赖序）

### T5-a 路由骨架 + 字号档 + Query 装配（本片有技术不确定项，先做 spike）

**做什么**
1. expo-router 分组：`src/app/(patient)/_layout.tsx` 建 Tabs 五槽（今日/药箱/记录/我的/设置），对齐 web `web/src/components/layout/BottomNav.tsx`（5 项，图标 + 文字并用）；录入与草稿确认仍走 stack push（`src/app/intake.tsx`、`src/app/drafts/[id].tsx` 已在 T4 落地，需迁进分组外的 stack）。
2. OnboardingGate 等价物：web 的守卫不跳转，是**全屏声明卡覆盖整个 RouterProvider**（`web/src/components/OnboardingGate.tsx:12` 键 `anxin-onboarded`、`:21` 读 `localStorage==='1'`、`:49` 写 `'1'`）→ mobile 换 AsyncStorage 同键、声明卡文案逐字照搬，禁止新写一套话术。
3. **字号全局缩放（本片最大不确定项）**：web 靠 `document.documentElement.dataset.scale` 驱动 rem（`components/layout/FontScaleSync.tsx:11`），RN 无对应物。**先做 spike 定方案**，候选两条：① 根布局按档给所有 `Text` 切 NativeWind 基类（要求全 app 文字统一走 `@/components/ui/text`，禁裸 `<Text>` 定字号）；② RN 原生 `allowFontScaling` + 自定义 `Text` 包一层 `pixelRatio`。选定后写进本文件（不许留成口头结论）。
4. QueryClient 装配在 `_layout`，`staleTime: 30_000`（对齐 `web/src/App.tsx:11`）。

**完成标准**：五 tab 可导航且样式互不串；字号两档在真机各页均生效、长文案不截断；杀进程重开字号保持；`typecheck`/`lint` 绿。

## 7. 已知风险（提前登记，翻车不算意外）

1. **字号全局缩放**（T5-a-3）：RN 的 rem 语义缺失是本项目第一次遇到；spike 若两条候选都不满意，允许第三方案（自定义 `Text` 组件 + 档位乘数），但必须回写本文件并同步 §6 第 2 条判据。
2. **原生依赖与代理**：AsyncStorage / expo-file-system / expo-sharing 都要重新出包，Gradle 依赖拉取依赖 v2rayN 在线（T4 实测：代理关着 → `Can't connect to SOCKS proxy`，BUILD FAILED）。
3. **`expo prebuild` 会先删 `android/`**（不加 `--clean` 也一样），目录被 Gradle 占住时报 `EBUSY` 中止；`android/` 不入 git，删了只能 prebuild + 三个镜像补丁重建（`packages/mobile/README.md` 已记）。能不 prebuild 就不 prebuild（自动链接已覆盖 expo-image-picker 的先例）。
4. **提醒队列在客户端内存**（`core/src/stores/reminderQueue.ts`），RN 切后台即断——这是 T8 要解决的，T5-b 只做到「页内到点提醒与 web 一致」，页外提醒一律不承诺。
