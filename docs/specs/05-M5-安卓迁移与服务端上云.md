## T1. 服务端上火山引擎（`app/` 零代码改动）

**做什么**

1. 购 ECS 2C4G（新客促销价优先；买前用官网计算器核实价格——本方案默认**不用 RDS**，docker 自托管 **postgres:18-alpine**（与本地实跑一致，ADR #8 已修订到 18））；
2. 安全组：仅开 22（限源 IP）与 80/443；8787 过渡期直出；数据库不进公网——compose 内 5432 映射改为 127.0.0.1 绑定或不映射；
3. 生产部署物 `app/deploy/`：`docker-compose.prod.yml`（api + postgres + caddy）+ `Caddyfile` + `.env.example`（真实 `.env` 只在服务器，不入 git）；
4. 数据迁移：优先重建——`db:migrate` + `db:seed` + `db:seed-interaction-rules`（mock 阶段重建成本≈0）；`pg_dump` 恢复（18→18 同版本）仅作兜底；
5. 过渡期外露：裸 IP `http://IP:8787`（APK 侧 cleartext 放行见 T3）；**并行启动**域名购买 + 备案（1–3 周），备案下来后 Caddy 签 HTTPS、APK 改 `EXPO_PUBLIC_API_URL` 重打包、关闭 cleartext；过渡期用 8787 非标端口的原因：未备案域名解析到大陆 IP 时 80/443 会被云厂商拦截——不要「顺手」改到 80。域名持有者须与备案主体一致（常见返工点）；
6. 运维底线：云盘快照每日 + `pg_dump` cron 每日；一个 uptime 监控（UptimeRobot 或等价）；LLM key 只存在于服务器 `.env`。

**完成标准**：`curl http://IP:8787/api/health` 200；真机浏览器打开医生端 Insight 正常；web 患者端 H5 正常；快照与备份 cron 各配置一次并实测恢复一条数据；`git status` 干净（deploy 物入库，.env 不入）；e2e/Playwright fixtures 套件（AI_MODE=fixtures）对火山部署跑一遍全绿（如需 prod target 配置项支持，允许改 e2e 配置）——服务端迁移的最佳验收。

## T2. 前端逻辑层抽包 `@anxin/core`（路线 A：逻辑公用，渲染分家）

**做什么**

1. 新建 `app/packages/core`，迁移 `web/src` 的平台无关部分；web 改为从 `@anxin/core` 引入；
2. **接缝分类表**（逐文件处理，不整包平移）：
   - `api/`（276 行）、`stores/` 持久化层：直接进 core；persist storage 适配器注入（web localStorage / mobile AsyncStorage）；
   - `lib/intake.ts` 纯部分（assessQuality、validateFile、mapIntakeFailure、文案常量）：直接进 core；
   - `lib/intake.ts` 的 `computeImageStats`（canvas 像素统计，171-219 行）：core 定接口；web 保留 canvas 实现；RN 一期可降级不出预检（预检本就「建议不拦用户」），二期再补实现；
   - `lib/speech.ts`：core 定 speak/isSupported 接口与降级语义；web 现实现，mobile 用 expo-speech；
   - `stores/intakeSession.ts`（原图交接）：类型改平台无关（web objectURL / RN fileURI）；
3. **intake 状态机抽为 core 纯决策函数**：现状住在 `IntakeFlow.tsx` 组件内部（Step 第 59 行、run 107-145、onFile 147-170、applyFailure/backToUpload/switchEntry）——抽成「输入（当前步骤+事件+结果）→ 输出（迁移结果+动作描述）」的纯函数 + 单测，网络/文件等 IO 留平台层执行；web 侧 IntakeFlow 同步改消费（注意：`run()` 为异步编排——调 detectImage 后按结果分支，抽取含异步效果拆解，非机械平移）；
4. 架构纪律（CI 检查）：core 禁 react-dom 与 DOM 用途——按「用途」检查，`setInterval` 这类 RN 亦有的全局不误伤；
5. 类型与 zod 契约继续走 `@anxin/shared`（不动）。

**完成标准**：web typecheck + 全测试绿；reducer 单测覆盖六步流转（upload/quality/processing/mismatch/failure/drafts）；core DOM 用途检查通过；web 界面行为无变化（人工过药箱+录入+咨询）。

## §9. 风险与止损线（可证伪）

1. **T4 第一周末骨架不通**（真机拍照→OCR 链路质量或连通性翻车）→ 录入链路重估，整个迁移价值重估；
2. **T8 白名单后提醒仍大面积不可靠** → 提醒载体重估（公众号模板消息 / 服务端推送路径重新上桌）；
3. **T5 结束时主线进度 <50%** → 实际速率低于估算，砍范围不拖工期：先砍 T9 图表、再砍语音，保录入+提醒两条命脉。
