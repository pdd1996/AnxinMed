## T1. 提取器 v2：bbox 阅读顺序 + 表格 Markdown 重建（§3.5 根治）

**根因**：`extract.py#extract()` 用 `'\n'.join(page.get_text() for page in doc)`，`get_text()` 按**内容流顺序**输出文本块；表格单元格在 PDF 里是后画的对象，于是整张表被排到页尾，跨页时错落到下一段正文中间（结构脂肪乳【用法用量】混入组份表、培哚普利提示框插断句子、氟康唑【注意事项】混入不良反应表碎片）。

**做什么**

1. **按 bbox 重建阅读顺序**（每页）：
   - 取 `page.get_text("dict")["blocks"]` 的文本块 bbox；
   - 取 `page.find_tables()` 的表格 bbox 与单元格；
   - 完全落在表格内的文本块**丢弃**（其文字由表格重建承担），其余文本块与表格按 `(y0, x0)` 排序拼接；
   - 表格以 **Markdown 表**插入到其 bbox 所在的阅读位置，而不是页尾；
2. **表格渲染**（纯函数，可脱 PDF 单测）：
   - 单元格文本只做空白归一化：`<br>` → 空格、连续空白折叠，不增删字符；
   - `| a | b |` + 分隔行（首行为表头）；空单元格保留占位；
   - 单行/单列表格视为误判，回退为原文本块（不进 Markdown）；
3. **跨页续表合并**：上一页最后一项是表格、且其 bbox 触底，本页第一项是表格、且其 bbox 触顶、列数相同 → 合并为一张表（重复表头行去重）。合并判据做成纯函数 + 单测（构造合成 bbox，不读 PDF）；
4. **单元格覆盖率校验（安全网）**：对每张表，把表格 bbox 内原文的非空白字符多重集与重建文本比对；覆盖率 < 0.98 → **该表回退**为原始文本块（宁可保留拉平文本，不丢字），并记入抽取报告 `tableFallbacks`；
5. `EXTRACTOR_VERSION` → `manual-pdf-2026-11-15`；`fitz` 保持可选导入（纯函数单测不需要 PyMuPDF）；
6. 新增诊断入口：`python tools/manual-pdf/extract.py --audit <pdf>` 打印每页表格与回退原因（供抽检定位）。

**完成标准**

- `python tools/manual-pdf/test_extract.py` 全绿，且新增单测覆盖：`render_table`（转义/空单元格/`<br>`）、`order_page_items`（表格在页中）、`should_merge_continuation`（触底+触顶+同列数）、`table_coverage`（覆盖不足回退）；
- 四份已知样本逐页对照肉眼通过：
  - 结构脂肪乳：组份汇总表回到第 2 页顶部（【成份】段内），【用法用量】不再混入表格；
  - 度拉糖肽：【不良反应】频率表按行列重建，且跨页续表合并为一张；
  - 培哚普利：「培哚普利禁止用于妊娠期。」提示框回到页面顶部，不再插断句子；
  - 氟康唑胶囊：【注意事项】不再出现不良反应表碎片；
- 单页耗时 ≤ 0.1s（1257 份全量重跑 ≤ 30min，可并行）。

## T2. 批准文号按规格归属（§3.6）

**做完什么**：`parse_approvals(raw, specs)` 重写分组逻辑。

**做什么**

1. **行内规格前缀优先**：一行内出现 `0.25μg`/`①5mg`/`(1)110mg` 这类「规格 + 文号」组合时，按该行的规格 token 归属到对应 spec，不再依赖「标签：文号」冒号分组；
2. **一行多组**：`0.25μgH20000065；0.5μgH20000066` 这类同一行写两组，按分隔符切开后各自归属；
3. **同规格多文号**（正常情形）：`布地奈德鼻喷雾剂` 3 个证号、`阿仑膦酸钠` 3 个证号——同规格行内出现的多个文号全部归属该规格，排序仍「首个非分包装」优先；
4. **一行覆盖多规格**（正常情形）：`1）50mg 2）200mg` 这类设计，两个规格都拿到该文号；
5. **无法分组**：多规格 PDF 中既无规格前缀、又无法按行归属的文号 **留空并告警**（写入 `unmapped`），**禁止退化为每个规格全挂**；单规格 PDF 直接全归属（无歧义）；
6. 告警文案进入 `curationNote`（沿用现有「批准文号分组与规格未能一一对应」note，措辞改为「未能归属，已留空」）。

**完成标准**

- 单测覆盖：阿法骨化醇（两行两文号）、阿立哌唑（①②）、氟康唑胶囊（(1)(2)）、达比加群酯（无序号两行）、布地奈德（同规格三文号）、伏立康唑（一行两规格）、无法归属（留空 + 告警）；
- 四份已知错误样本重提取后，每行 `approvalNumbers` 恰为自身规格的文号；
- 全库审计脚本产出：多文号行 344 → 只保留「同规格多包装」与「一行多规格」两类正常情形，逐条可解释（报告落 `data/m7-reports/approvals.jsonl`，本地）。

## §4 度量口径

### 4.1 字符完整性（安全指标）

同一段落的新旧文本，去掉空白、`|`、`---` 分隔行后，比较**字符多重集**：

- 差异 = 0：通过；
- 差异 > 0：该行列入「需解释」，逐条人工看（可能是表格合并导致重复表头去重，属预期）。

### 4.2 表格拉平签名（缺陷指标）

段落同时满足下列任一即命中：

1. `十分常见` …（80 字内）`常见` …（160 字内）`偶见|罕见`；
2. 含 `系统器官分类` 且含 `常见`。

重提取后，命中行若仍无 Markdown 表格结构（`|`），记为残留。

### 4.3 兜底条款

表格识别不是 100%：PDF 里用**空格排版、无框线**的表格，`find_tables()` 可能识别不到。M7 的验收是「已识别表格行列归属 100% 正确 + 残留行登记」，不是「全库零残留」。残留行必须：
- 在 T4 报告里逐条列出（行数、PDF、段落）；
- 登记为本任务书 §5 的「残留表格（源文无表格结构）」；
- 咨询侧防线是否撤销按 T6 判定。
