### 5.2 T2 · 提示卡文案分层（2026-11-17）

**问题**（T1 截图暴露）：interaction-check 的 5 条提示把整句说明书 note 直接塞进列表，卡片很长，老年用户读不完。

**改法**：

- `ConsultSections` 增加可选 `details: {title, body, source?}[]`；
- `renderInteractionsSections`：`keyPoints` 只放 `[级别] 药1 + 药2`（短摘要）；逐字 note 与来源进 `details`；
- `AnswerCard` 渲染「展开原文（N 条）」`<details>`，默认收起；
- 其他模板不填 details，旧客户端忽略该字段。

**验证**：

| 项 | 结果 |
|---|---|
| API 单测 | `consult-dataquery` 32/32（短摘要不含 note/来源；details 含 title/body/source） |
| Web 单测 | `AnswerCard` 10/10（数据查询卡 + 展开原文 + 来源） |
| E2E | `curated-interactions` 1/1：摘要 5 条短文案，展开后逐字原文可见；0 次 LLM |
| 全量回归 | API **665** / Web **92** / E2E **20**；typecheck / lint 绿 |
| 截图 | `data/m11-reports/curated-interactions-ui.png`（本地） |

**边界**：只改展示分层，**规则内容/note/quote 一字未动**；完整原文仍可展开查看，来源仍可见。
