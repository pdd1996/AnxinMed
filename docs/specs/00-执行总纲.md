## 0. 执行协议（先读这一节）

1. **顺序执行**：严格按 M1 → M2 → M3。每个里程碑内部也尽量按任务编号顺序（个别任务已标注可并行）。
2. **真相源优先级**：本任务书 > 技术方案 08 > ADR 07 > PRD 06。任务书与上游文档冲突时，**停下来向用户报告冲突**，不要自行裁决。
3. **验收驱动**：每个任务有明确的「完成标准」，写完必须逐条自验并把验证命令与结果附在交付说明里。完成标准未达成 = 任务未完成。
4. **改动边界**：只改 `app/`（及任务书明确允许的 `docs/`、`demo/` 小改动）。`demo/` 原则上只读——它是迁移参照物，不再演进。
5. **禁止事项**：
   - 禁止把任何 API Key、连接串密码写进代码或提交进 git；
   - 禁止让模型输出（LLM/VLM/OCR）绕过 zod `safeParse` 直接入库（见 §3 全局约定）；
   - 禁止生成相互作用规则库条目内容（只能抄录，PRD §7.8.1）；
   - 禁止实现"从药盒/标签自动抄录用法用量"（PRD §0.1 V2.1 已删除该能力）；
   - 禁止静默吞错——失败必须可见（错误码 + 用户可理解的信息）。
6. **每个任务完成后**：`git commit`，提交信息格式 `M1-T3: resolveUser 中间件与本地用户解析`。里程碑完成后打 tag：`m1-done`、`m2-done`、`m3-done`。
7. **被卡住时**：优先重读 PRD 对应章节；仍无法解决则停在任务边界，输出「已完成 / 未完成 / 阻塞原因」清单，交回用户，不要为了"看起来完成"而降标准实现。

## 3. 全局约定（所有任务必须遵守）

### 3.1 工程与语言

- pnpm 单仓：`app/pnpm-workspace.yaml` 收 `packages/*`；Node ≥ 20；所有包 `"type": "module"`、TypeScript strict。
- 包边界：`shared` 不依赖任何其他包；`api` 与 `web` 都只依赖 `shared`；`web` 不直接 import `api` 的代码（类型经 `hc<AppType>` 获得）。
- 命名：DB 表/列 snake_case，TS 代码 camelCase，枚举值用上表目标值。
- 错误响应统一 `{ ok: false, code, message }`；成功响应 `{ ok: true, ...data }`（列表类用 `items`）。

### 3.2 数据与安全不变式（每次写库前自查）

1. **药品主数据库 ≠ 用户药箱**：一切写入 `drugs`（用户域）的数据必须已经过用户确认或手动录入；
2. **医嘱只抄录不生成**：plans 的 dose/frequency/duration 只能来自 ① 确认的处方原文（transcribed/user）② 用户自填（user）。任何模型输出不得直接写入；
3. **一切模型输出过 zod**：层检测 / VLM 身份 / OCR 兜底解析 / 咨询回答分级，必须 `safeParse` 通过才使用；
4. **零泄漏断言**：任何持久化输出（库、日志、第三方请求 body）中出现手机号/身份证/姓名/地址模式 = 0，CI 强制；
5. **凡进档案，最后一道门是用户**：没有绕过确认页的写路径；
6. **凡模型调用必有降级路径**：模型 503/超时不影响药箱、计划、提醒、记录。

### 3.3 测试纪律

- **金字塔与重心**（刻意压在底层，E2E 只验接线）：
  1. **纯函数单测（大头）**：管线每步、脱敏每层、匹配规则、范围校验、守门规则全为纯函数，零 I/O、确定性，秒级回归——算法正确性靠这层保证；
  2. **模型边界单测**：AI 客户端请求体组装（断言只含白名单字段）、`safeParse` 拒绝非法模型输出、错误映射——fetch 全 mock 不真调；
  3. **集成测试**：`app.request()` + 独立测试库（`anxin_medication_test`），覆盖确认事务原子性/回滚、零泄漏断言、防重复 409、userId 隔离；
  4. **E2E 仅五条 golden case**：外部模型经统一 `AiClients` 接口依赖注入，CI 用录制审核过的 fixture 回放（机制见 M2-T10），真实管线仅发布前手动跑。
- 每个任务自带的测试随任务提交（Vitest，与被测代码同包）；M1-T6 建好 vitest 配置后，此前任务补写。
- 纯函数优先可测：管线每步、脱敏每层、匹配规则、范围校验全部为纯函数。
- 集成测试用 `app.request()`，不占端口。测试库独立：`anxin_medication_test`，测试 setup 跑迁移。

### 3.4 提交与验证

- Windows 开发环境（Git Bash）：脚本要兼容（避免硬编码 unix-only 路径行为）；.env 已存在于 `app/` 与 `app/packages/api/`，**不要覆盖、不要提交**。
