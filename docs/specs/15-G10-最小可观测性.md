## 1. 目标与完成判据

**目标（G10 关闭判据）**

1. **错误日志落盘**：API 未处理错误（5xx）与进程级未捕获异常写入本地 JSONL，按日轮转/保留，可从宿主机查看；
2. **模型调用计数**：按客户端统计调用次数/成功失败/重试/延迟/token 用量，跨重启不丢当日累计；
3. **日预算告警**：按 token 估算当日模型成本，达到日预算 80%/100% 时输出可见告警（每档每日一次）；
4. **限流**：LLM 路由按用户限流、全 API 按 IP 兜底，超限返回 429 + Retry-After，保护模型成本与单实例稳定性；
5. 观测端点受独立 token 保护；日志与指标**不含用户内容/PII**；不引第三方依赖。

**非目标**

- 不做分布式 tracing/APM、不做外部告警通道（邮件/短信/Webhook）——生产环境由 UptimeRobot + 宿主机日志/监控承接；
- 不做预算**熔断**（超预算只告警不拦截）；不做多实例共享限流（单实例内存，多副本前需换 Redis/DB 计数）；
- 不做审计日志留存策略（属 G14 数据生命周期）。

**完成判据**

| # | 判据 |
|---|---|
| 1 | `logs/api-errors-YYYY-MM-DD.jsonl` 在 5xx/未捕获异常时落盘；字段含 ts/event/code/status/method/path/requestId/errorName/message/stack；无请求体/用户问题/模型输出 |
| 2 | 50MB/日轮转与 14 天保留生效（单文件 10MB → `.1`） |
| 3 | `callJson` 单点埋点：attempts/success/failure/retries/latency/tokens 可按 client 读；`metrics-YYYY-MM-DD.json` 原子落盘，重启后当日累计恢复 |
| 4 | 预算 80%/100% 各触发一次 `[obs:budget]` console.warn，跨重启不重复告警 |
| 5 | LLM 路由超 10 次/分钟或 200 次/24h → 429 `RATE_LIMITED` + `Retry-After`；IP 240/min 兜底且 `/api/health` 豁免 |
| 6 | `GET /api/observability/summary`：未配 `OBS_ADMIN_TOKEN` → 404；错 token → 401；正确 → 200 + 当日计数/成本/预算/限流/错误数 |
| 7 | 既有 API 测试全绿（688 → 721）；typecheck/lint 不退化；E2E fixtures 不受限流影响 |

## 2. 关键决策（与理由）

| # | 决策 | 理由 |
|---|---|---|
| D1 | 日志落本地 **JSONL 文件**（`LOG_DIR`，默认 `./logs`），不引日志服务 | 单实例 staging、零外部依赖、`tail`/`grep` 即用；结构化 JSONL 便于后续采集。 |
| D2 | 只落 **5xx/进程级未处理错误** | 4xx 是业务正常失败路径（响应本身已可见），全量落盘会淹没真正的错误面；与「禁止静默吞错」不冲突。 |
| D3 | 模型调用在 **`lib/ai/http.ts:callJson` 单点埋点** | 所有 AI 客户端（qwen/ocr/baichuan/qwen-text/deepseek）都走此函数，零散落点易漏；只读 `usage` 数值，不碰 choices/content。 |
| D4 | token/成本口径与 [docs/11 §2.2](../11-咨询Agent评估与指标口径-M4.md) 一致：`cached` 是 `prompt_tokens` 子集，不重复计价 | 与 M12 长稳实测的成本估算可直接对账；价格用 env 可调（默认 0.8/2.7/0.1 元每 M tokens）。 |
| D5 | 预算**只告警不熔断**，阈值状态随 metrics 文件持久化 | 最小实现；熔断属业务策略（受控试点期由运维盯告警）。80%/100% 每档每日一次，避免日志刷屏。 |
| D6 | 限流用内存滑动窗口（单实例），`NODE_ENV=test` 默认关闭 | 与 G7 登录限流同构（单容器 staging）；测试关闭避免 688 条既有集成测试误伤，`RL_FORCE=1` 可强制验证。 |
| D7 | 观测端点用 **`x-obs-token` + `OBS_ADMIN_TOKEN`** 常量时间比对；未配置 env → 404 | 不引入管理员账号体系；未配置时与 notFound 文案逐字一致，不暴露端点存在性。 |
| D8 | IP 取 `x-forwarded-for` 首段（Caddy/反代），直连裸 IP 时可伪造 | 仅作兜底，不承担鉴权；接 HTTPS/Caddy 后由反代覆盖该头。 |

## 4. 行为规格

### 4.1 错误日志

- 路径：`${LOG_DIR}/api-errors-YYYY-MM-DD.jsonl`（本地默认从 `app/packages/api` 启动时为 `./logs`；容器 `/app/logs`）。
- 轮转：单文件 10MB → `api-errors-YYYY-MM-DD.1.log` 式后缀；保留 14 天（首次写入与每日首次写入时清理）。
- 字段：`ts, level, event, code, status, method, path, requestId, errorName, message, stack`；`path` 只取 pathname 不含 query；`message/stack` 过 L3 PII 模式脱敏并截断（1000/4000）。
- 结构上不含请求体、用户问题、模型回答/段落内容。
- 进程级：`uncaughtException`/`unhandledRejection` 落盘后 `console.error` + `exit(1)`（不吞、不裸奔）。

### 4.2 模型调用计数与成本

- 计数维度：client（qwen/ocr/baichuan/qwen-text/deepseek）× 当日；字段 `attempts/success/failure/retries/avgLatencyMs/tokens{prompt,completion,cached,total}`。
- 每次 `callJson` 尝试都计数（含重试、4xx 拒绝）；成功响应若带 `usage` 则累加 token。
- 落盘：`${LOG_DIR}/metrics-YYYY-MM-DD.json`（tmp + rename 原子写）；进程启动读取当日文件恢复累计，预算与告警状态不因重启清零。
- 成本估算：`(prompt - cached) × 输入价 + cached × 缓存价 + completion × 输出价`，价格 env 可调。

### 4.3 日预算告警

- env：`LLM_DAILY_BUDGET_CNY`（默认 20）、`LLM_PRICE_INPUT_CNY_PER_M`（0.8）、`LLM_PRICE_OUTPUT_CNY_PER_M`（2.7）、`LLM_PRICE_CACHED_CNY_PER_M`（0.1）。
- 达到 80% / 100% 各输出一次：`console.warn('[obs:budget] {...}')`（含 level/threshold/spent/limit/percent/date）。
- 状态持久化在 metrics 文件；跨重启不重复告警。

### 4.4 限流

| 档 | 维度 | 默认 | env |
|---|---|---|---|
| LLM 路由分钟档 | userId | 10 次/分钟 | `RL_LLM_PER_MIN` |
| LLM 路由日档 | userId | 200 次/24h 滚动 | `RL_LLM_PER_DAY` |
| 全 API 兜底 | 客户端 IP | 240 次/分钟 | `RL_IP_PER_MIN` |

- LLM 路由：`POST /api/consult`、`POST /api/intake/{prescription,drug,detect}`、`POST /api/insight/{summary,queue-summary,ask}`。
- 豁免：`/api/health`（外部可用性监控不能误伤）；`NODE_ENV=test` 默认关闭，`RL_FORCE=1` 强制。
- 超限：`429 { ok:false, code:'RATE_LIMITED', message:'操作太频繁，请稍后再试' }` + `Retry-After` 秒；被限流请求不执行业务。

### 4.5 观测快照

`GET /api/observability/summary`（无需用户登录；注册在 `resolveUser` 之前）

| 鉴权状态 | 响应 |
|---|---|
| `OBS_ADMIN_TOKEN` 未设置 | 404 `{ok:false,code:'NOT_FOUND',message:'路由不存在'}`（与 notFound 逐字一致） |
| 缺/错 `x-obs-token` | 401 `{ok:false,code:'AUTH_INVALID'}` |
| 正确 | 200 `{ok:true,data:{date, modelCalls{byClient,totals}, estimatedCostCny, budget{limitCny,spentCny,percent,status}, rateLimited, errors, uptimeSec, version}}` |

## 7. 已知边界与风险

1. **单实例内存限流**：多副本部署前换共享存储（Redis/DB 计数）；进程重启清零（限流属瞬时保护）。
2. **预算只告警不熔断**：超预算不会自动停止模型调用；受控试点期由运维按 `[obs:budget]` 预警人工处置。
3. **无外部告警通道**：预算/错误日志告警需宿主机/外部监控（UptimeRobot、云监控）接走；G10 只保证「可观测」，不保证「会通知到人」。
4. **rateLimited/errors 计数进程重启清零**（metrics/预算累计已持久化）。
5. **metrics-*.json 不自动清理**（体量小；G14 数据生命周期统一处理）。
6. **IP 取 `x-forwarded-for` 首段可伪造**：仅兜底，不承担鉴权；HTTPS/Caddy 上线后由反代覆盖。
7. **日志在容器内宿主机 bind mount**：磁盘容量由宿主机负责（14 天保留可兜底，仍需监控磁盘）。
