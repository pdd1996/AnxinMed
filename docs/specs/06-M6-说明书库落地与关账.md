## 1. 缺陷与根因

M6 用 `tools/manual-pdf/extract.py` 把 NMPA 版式 PDF 抽成说明书草稿。全库重跑 1257 份 PDF
（1602 行）后确认三类解析缺陷，均属「规格字段」而非正文段落：

| # | 现象 | 根因 | 实测样本 |
|---|---|---|---|
| 1 | 规格丢前导数字（`0.75mg→75mg`、`3ml→ml`、`1g←0.1g`、`2.0mg→0mg`） | 编号剥离正则 `^[\(（]?\d+[\)）]?[.、]?\s*` 把「0.」当编号吃掉 | 度拉糖肽、门冬胰岛素、阿卡波糖、拓培非格司亭等 51 行 |
| 2 | 规格在括号内逗号/分号处被切断（`...复方氨基酸` 截断） | 条目按 `；` 切分时不看括号深度；`(16)(13)` 被当列表标记 | 结构脂肪乳、乳果糖、丁酸氢化可的松等 25 行 |
| 3 | PDF 排版折行被当独立规格行（一行切成 2–6 行） | 多行规格直接按行切，未判断「行是否写完」 | 氟替美维、钆特酸葡胺、人促红素、脂溶性维生素等 |

补充：编号剥离那处已在 11-12 由 `M6-T9-fix: 规格多行编号误吃数字与通用名重复冒号修正` 修过，
但**已入库的 1602 行没有重跑**，所以库内仍是旧值——本次补齐解析器剩余两处 + 全库重跑 + 落库修复。

## 2. 解析器修复（tools/manual-pdf/extract.py）

- 裸编号 `1）` 纳入剥离范围（`LIST_MARKER_RE`）；
- 规格段切分改为**括号深度感知**：`[]`/`（）` 内的 `；`、「(16)」「(13)」不切；
- 折行判定 `line_complete()`：行内括号未闭合 / 行首右括号 / 超长 / 行尾是连接词 → 视为排版折行，整段当一个规格；
- 折行拼接 `join_lines()`：中文、化学式、数值+单位之间不插空格；英文单词与表格列之间保留空格；
- `extractorVersion` → `manual-pdf-2026-11-14`；`fitz` 改可选导入，纯解析函数可脱 PDF 单测。

验证：`python tools/manual-pdf/test_extract.py` → **27 tests OK**；HEAD 版 vs 新版在 919 个唯一
【规格】段上 diff = 33 段 / 70 行，逐条核对均为修复。

### 3.5 已知提取缺陷：表格被文本层拉平（行列归属丢失）

> ✅ **已修复（M7，2026-11-16）**：提取器改为 bbox 阅读顺序 + `find_tables` 行列重建（Markdown 表）、跨页续表合并、行级保字校验；全库重提取后 **PDF 级 2375 张表**（行级累加 3529）结构化、760/1588 行含表，旧签名 351 行中 288 行已重建，残留 63 行经分类均为假阳性。口径定义见 [07-M7 §5.0](./07-M7-说明书库缺陷修复.md)。

- **现象**：`extract.py` 以 `page.get_text()` 按文本块顺序拼页面，表格单元格被拆成独立块后按块序相接，
  字符完整但行/列归属丢失（例：度拉糖肽【不良反应】表，「急性胰腺炎=罕见」「非机械性肠梗阻=未知」
  与相邻单元格混在段落里，AI/人都无法可靠判断某反应属于哪一档）。
- **加重形态（跨页/顺序异常）**：表格在 PDF 文本层被排到页尾时，会整体**错落到下一段中间**，
  并劈开跨页句子。实例：结构脂肪乳(20%)/氨基酸(16)/葡萄糖(13%)注射液——组份汇总表
  （氨基酸 38g/60g、电解质…，对应 1206ml/1904ml 两规格）在版面上属第 2 页顶部、**【成份】表尾**，
  文本层却排在第 2 页末尾，结果落进【用法用量】的「…中至重度代谢应激患」与「者，氮需求量为…」
  之间。全库同类（用法用量段混入组份/电解质/能量表特征）文本启发式命中 **19 行**，含
  结构脂肪乳 1206ml/1904ml、氟康唑氯化钠 4 行等；该计数为下限，精确清单以 M7 表格识别为准。
  同属本节根因，M7 按 bbox 位置重建后表格回原位。
- **人工复核确认（2026-11-15 · 5 行专项）**：5/5 行规格通过；其中 **3 行**在非不良反应段发现表格泄漏：
  阿卡波糖【注意事项】混入不良反应频率表（并把「低血糖」劈成「低血／糖」）、结构脂肪乳【用法用量】
  混入组份汇总表（劈句）、乳果糖【注意事项】混入用法用量表片段（「婴儿／每日5毫升」，含重复）。
  结论：跨段泄漏是普遍形态，影响面大于 232 行的频率表估计；M7 的 bbox 位置重建必须覆盖**全部段落**，
  不能只修【不良反应】。
- **人工复核确认（2026-11-15 · 20 份抽检）**：
  - 氟康唑胶囊【注意事项】开头即不良反应表格碎片（「、低钾血症／精神性疾病／嗜睡、失眠…」），

### 3.6 已知提取缺陷：批准文号未按规格归属

> ✅ **已修复（M7，2026-11-16）**：`parse_approvals` 改为按行内规格 token 归属（含单位换算/无冒号/①②标记/一行多组），无法归属留空告警；319 行文号重算，脏格式 56→0，多文号行 344→141（只剩正常情形）。详见 [07-M7 §5](./07-M7-说明书库缺陷修复.md)。

- **现象**：多规格合并 PDF 的【批准文号】段按规格分行书写（如 `0.25μg国药准字H20000065`），
  `parse_approvals` 依赖「标签：文号」冒号分组；无冒号/用「；」分隔时分组失败，退化为
  **每个规格行都挂整组文号**。
- **确认实例（2026-11-15 抽检发现）**：
  - 阿法骨化醇软胶囊：源文 `0.25μg=H20000065`、`0.5μg=H20000066`，两行都挂两个；
  - 阿立哌唑片：源文 `①5mg=H20041506`、`②10mg=H20041507`，两行都挂两个；
  - 氟康唑胶囊：源文 `(1)50mg=H10960165`、`(2)0.15g=H10960164`，50mg 行挂两个；
  - 达比加群酯胶囊：源文 `110mg=H20213234`、`150mg=H20213235`，150mg 行挂两个。
- **正常情形（不算缺陷）**：同一规格的多包装/进口注册证 + 分包装（布地奈德鼻喷雾剂 3 个证号、
  阿仑膦酸钠 3 个证号），以及一行覆盖两规格的设计（伏立康唑「1）50mg 2）200mg」）。
- **另一类问题**：氨氯地平阿托伐他汀钙片【批准文号】段定位错——抽到的是【药物相互作用】表格内容，
  文号字段不可信；与本节根因不同，属段定位缺陷，M7 一并复查。
- **影响面（下限）**：同 PDF 多规格行共享同一组多文号的 PDF **93 份**（文本特征扫描）；
  其中含上述正常情形，精确错误清单以 M7 修复时逐份核对为准。
- **影响评估**：`approvalNumbers` 用于身份指纹与展示；主批准文号 tie-break 取「首个非分包装」，
  当前恰好正确，直接业务风险中低，但属于身份元数据错误，必须修。
- **修复（M7）**：`parse_approvals` 支持无冒号/「；」行——按行内规格前缀（`0.25μg`、`①5mg`、
  `(1)110mg`）匹配 `strength_tokens` 分组；无法分组时**留空并告警**，不得退化为全挂；
  重跑 93 份 PDF + 走 reviewed 修正通道（含审计）+ 重新生成抽检页人工复核。
- **关账口径**：本缺陷**不**作为单卡「存疑」判定；抽检遇到按已登记缺陷跳过（2026-11-15 20 份样本中
  4 份确认命中、1 份段定位问题、3 份多文号属正常）。

### 3.7 已知提取缺陷：商品名标签变体丢失

> ✅ **已修复（M7，2026-11-16）**：标签集合补「商品名」等变体；全库 25 行全部补齐（缺失 0）。详见 [07-M7 §5](./07-M7-说明书库缺陷修复.md)。

- **确认实例（2026-11-15 抽检发现）**：阿仑膦酸钠片（源文「商品名：福善美」）、

  其中 reviewed **6 行**。
- **影响评估**：商品名仅用于展示与短名检索，不进入身份指纹（`identityKey` 不含 brandName），
  业务风险低，但属于身份字段缺失。
- **修复（M7）**：标签集合补「商品名」变体；重跑 25 份 PDF 并更新 `drug_master.brand_name` /
