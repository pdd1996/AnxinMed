## 3. 已知问题与后续

1. **断网错误文案是技术英文**（`fetch failed: java.net.ConnectException: Failed to connect to ...`）：`core/bootstrapAuth` 把原始异常 message 直接交给 AuthGate 展示。G7 收尾不阻塞；**G8 出包前**在 `core/src/lib/auth.ts` 对网络类错误做中文归类（web 走同一条路径，随下次服务端镜像更新）。
2. **release 仍是 debug 签名**（见上表）：G8 需生成正式 keystore，并做成 `plugins/with-release-hardening.js` 一类的 expo config plugin（`android/` 不入 git，手改会被 prebuild 抹掉）。
3. **`pm clear` 被系统拒绝**（Binder 异常）：设备最后停在已登录 p-002 状态，交付前请手动退出登录或换 p-001。
4. 登录页大字档/键盘避让在 PJZ110 上正常；更小屏（<360dp）未覆盖。

## 4. 复跑方法

```bash
# 出包（构建机需代理，见 §1）
cd app && pnpm --filter @anxin/mobile android:release

# 安装
adb install -r app/packages/mobile/android/app/build/outputs/apk/release/app-release.apk

# 截图取证
adb shell screencap -p /sdcard/x.png && adb pull /sdcard/x.png app/backups/g7-evidence/
```

UI 自动化输入提示：中文输入法会把 `adb shell input text` 的 ASCII 转成全角/拼音（实测 `p-001` → `怕－001`），需先
`adb shell ime set io.appium.settings/.UnicodeIME`，测完 `adb shell ime set com.google.android.inputmethod.latin/com.android.inputmethod.latin.LatinIME` 恢复。
