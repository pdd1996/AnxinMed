## 1. 前置：重新出包并装机

【本机】先开 v2rayN（Gradle 钉了 `systemProp.socksProxyHost=127.0.0.1` / `Port=10808`，`packages/mobile/android/gradle.properties`），再出包：

```bash
cd app && pnpm --filter @anxin/mobile android:release
```

预期：`BUILD SUCCESSFUL`，末行打印 APK 路径。**失败若仍是 `Can't connect to SOCKS proxy`，就是代理没起来**，不要去改 gradle.properties。

【本机】出包后先验 05d §1-2 与 README 的三条硬指标（这条命令在仓库根执行）：

```bash
a=app/packages/mobile/android/app/build/outputs/apk/release/app-release.apk
ls -la "$a"                       # 时间戳必须是刚刚，否则装的还是旧包
unzip -l "$a" | grep -oE "lib/[A-Za-z0-9_-]+/" | sort -u   # 预期 lib/arm64-v8a/ 与 lib/x86_64/ 都在
```

【本机】装机（手机 USB 已授权调试）：

```bash
adb install -r app/packages/mobile/android/app/build/outputs/apk/release/app-release.apk
```

预期：`Success`。
