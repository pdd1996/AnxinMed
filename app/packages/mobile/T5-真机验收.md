## 1.0 清 A/B 基线数据（对公网服务器做删除，只由你手动执行）

代理起来前的空档可以做这步——它不出包、不依赖 v2rayN。**这是对线上演示库的破坏性写，代理侧不代跑**（本次已由权限层拦下，属预期）。

```bash
# 先回读，确认要删的就是这 4 条
curl -s "http://118.196.82.13:8787/api/drugs" | node -e "let s='';process.stdin.on('data',d=>s+=d).on('end',()=>{JSON.parse(s).items.forEach(i=>console.log(i.id,i.genericName,i.specification,i.confirmStatus))})"

# 逐条删（resolveUser 固定 p-001，无需带鉴权头）
for id in drug-0a93afa1-fd1a-4564-b331-c6b8590f1c58 drug-fbff820a-1cb5-4f18-833e-175ec3a3fdbf \
          drug-5496bbe4-5674-41ee-8553-562e161c4b4d drug-85c3d01f-d10d-4bf3-988c-2a56f8356bc6; do
  printf "%s -> " "${id:0:18}"; curl -s -X DELETE -o /dev/null -w '%{http_code}\n' "http://118.196.82.13:8787/api/drugs/$id"
done

# 回读验证：药箱应只剩 4 条 demo-drug-*，且 /api/plans 剩 4 条
curl -s "http://118.196.82.13:8787/api/drugs" | node -e "let s='';process.stdin.on('data',d=>s+=d).on('end',()=>console.log('drugs =',JSON.parse(s).items.length))"
```

预期：四条各 **`200`**（`routes/drugs.ts:31-35` 的 `okJson` 默认 200，不是 204；出现 `404 药品不存在` 说明这条已被删过，跳过即可），末行 `drugs = 4`。**若 `/api/records` 的 `summary.total` 与 `items.length` 仍差 1，那不是本次删除造成的**——见 05d §7 第 6 条登记的既有缺陷（孤儿记录被 innerJoin 吞掉）。

## 1. 前置：重新出包并装机

【本机】先开 v2rayN（Gradle 钉了 `systemProp.socksProxyHost=127.0.0.1` / `Port=10808`，`packages/mobile/android/gradle.properties`），**先 `netstat -ano | findstr 127.0.0.1:10808` 确认有 LISTENING 行再动手**，再出包：

```bash
cd app && pnpm --filter @anxin/mobile android:release
```

预期：`BUILD SUCCESSFUL`，末行打印 APK 路径。**失败若仍是 `Can't connect to SOCKS proxy`，就是代理没起来**，不要去改 gradle.properties。

【本机】出包后先验 05d §1-2 与 README 的三条硬指标（这条命令在仓库根执行）：

```bash
a=app/packages/mobile/android/app/build/outputs/apk/release/app-release.apk
ls -la "$a"                       # 时间戳必须是刚刚，否则装的还是旧包
unzip -l "$a" | grep -oE "lib/[A-Za-z0-9_-]+/" | sort -u   # 预期 lib/arm64-v8a/ 与 lib/x86_64/ 都在
```

【本机】装机（手机 USB 已授权调试）：

```bash
adb install -r app/packages/mobile/android/app/build/outputs/apk/release/app-release.apk
```

预期：`Success`。
