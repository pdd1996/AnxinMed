## 6. 与 web 的差异清单（T7 记账）

| # | 项 | 类型 | 说明 |
|---|---|---|---|
| 1 | 无右侧「我能帮你/我不会做」说明栏 | 刻意不同 | web `hidden lg:block`，手机单列不需要 |
| 2 | 无页内选药器 | 刻意相同 | web 已移除；对象药由药箱深链带入（05f D1-A） |
| 3 | 页面头部 = 原生 stack 标题 + 44px 图标工具栏 | 平台适配 | web 是薄头部 + 纯图标按钮；mobile 用图标+文字（历史/开新会话）保证可读性 |
| 4 | 新消息自动滚底 | 平台适配 | web 无显式滚动；手机聊天屏需要 |
| 5 | 传输失败常驻错误卡 + 重试 | 平台增强 | web 依赖 toast；mobile 额外保留可恢复卡（禁静默吞错） |
| 6 | 令牌色走实色 tint | 平台约束 | alpha 类在 RN 整条不落产物（README 同名坑） |
| 7 | 发送用按钮，无 Enter 发送 | 平台适配 | 多行输入 + 软键盘 |
| 8 | `buildSpeakText`/`STATUS_META`/`TOOL_LABELS`/`SECTION_KEY_LABELS` 在 mobile 复制 | 刻意重复 | web 冻结，不抽公共（05f §0-6） |
